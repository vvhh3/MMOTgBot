# Простое обучение

Реализовано 25 октября 2026 года. Обучение начинается после создания нового персонажа. Старым персонажам оно автоматически не включается.

## Сценарий

1. На главной появляется карточка «Первый день в районе». Дворник предлагает разобраться с ожившим мусорным пакетом.
2. Кнопка переводит персонажа на Площадь и начинает личный PvE-бой. Подсказки объясняют «Битва», выбор атаки и полоски здоровья. Используются обычный боевой движок и интерфейс.
3. За победу гарантированно выдаются «Кирпич с дипломом», 10 монет, 10 очков и 10 XP. Предмет появляется с анимацией. Кнопка результата открывает инвентарь.
4. В инвентаре подсвечено оружие. Нужно открыть предмет и нажать «Надеть». Подходит любое принадлежащее игроку оружие; надевание брони шаг не завершает.
5. Появляется сообщение об окончании обучения с анимированной галочкой и кнопкой возвращения в город.

Пропуск доступен в карточке вне активного боя. Он завершает обучение без выдачи новых наград. Уже выданные вещи и прогресс остаются. Во время боя можно воспользоваться обычным побегом, затем пропустить обучение на главной.

## Состояние и повторный вход

`PlayerDto.tutorialStep` и `players.tutorial_step` хранят этап:

| Этап | Значение |
| --- | --- |
| `welcome` | Поручение предложено |
| `battle` | Учебный бой начат, победы ещё нет |
| `equip` | Победа и награда получены; требуется надеть оружие |
| `complete` | Оружие надето; показано поздравление |
| `done` | Обучение закрыто, пропущено или не включено для старого персонажа |

Миграция `0031_first_adventure.sql` добавляет поле со значением `done`. Только серверный обработчик создания персонажа переводит его в `welcome`; клиент не может прислать готовый этап. Dev-сброс возвращает `done`, последующее создание включает обучение заново.

Этап сохраняется в БД. Повтор начала активного учебного боя возвращает ту же сессию. После обычного тайм-аута PvE в пять минут без действий, поражения или побега можно начать попытку заново. Перед новой попыткой здоровье восстанавливается. Награда выдаётся только за первую победу, вместе с переходом к `equip`, внутри транзакции завершения боя.

Учебный противник использует зарезервированный ID `-1`, создаётся при первом запуске поручения и не попадает в прогулки и список администрирования мобов. Изменение и удаление шаблона через API запрещены. У каждого игрока своя сессия; общий респаун не используется. Прямой запуск через `/combat/start` запрещён.

## API

Все маршруты требуют авторизацию:

- `POST /tutorial/start` → `{ player, state }`. Доступен созданному персонажу на этапах `welcome`/`battle`; возобновляет активный учебный бой либо создаёт новую попытку.
- `POST /tutorial/skip` → `{ player }`. Завершает обучение вне боя, не выдавая наград.
- `POST /tutorial/finish` → `{ player }`. Закрывает поздравление после экипировки; преждевременный запрос возвращает `409`.

Прогресс экипировки меняется только после успешного `/inventory/equip`. Отдельного API для произвольной установки этапа нет. Повтор закрытия безопасен.

## Анимации

- Появление и смена содержимого карточки: opacity и небольшой сдвиг.
- Плавное заполнение полосок прогресса.
- Три мягких импульса подсветки «Битва», приёма и оружия.
- Появление награды с увеличением.
- Прорисовка галочки завершения; карточка прокручивается в область видимости.

Используется уже подключённый `motion/react`. Настройка уменьшения движения учитывается через `useReducedMotion` и `prefers-reduced-motion`. Подсказки встроены в экран и не перекрывают элементы управления.
