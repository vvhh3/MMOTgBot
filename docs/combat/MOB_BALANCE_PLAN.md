# Обсуждение нового набора противников

25 октября 2026. Согласована основа поведения встреч. Пользователь разрешил реализацию замены старых мобов и переработки квестов, но сначала попросил выбрать названия. Первый выпуск ограничен локацией «Площадь». Численные параметры, добыча и названия ещё обсуждаются. В рамках этого этапа изменения в код и игровую БД не вносились; существующие мобы пока не удаляются.

## Подтверждено пользователем

- Встречи личные. Победа одного игрока не убирает противников у другого.
- Кнопка «Сражаться» относится только к PvP с другими игроками. Встречи с мобами, включая боссов, разыгрываются при прогулке; отдельный поиск PvE через «Сражаться» не вводится.
- Уровень противника подстраивается примерно под текущий уровень персонажа. По последнему уточнению первый выпуск — только на «Площади»; новые встречи с мобами в остальных локациях пока не добавляются.
- Первую версию балансируем для персонажей 1–8 уровней с возможностью расширить диапазон позже.
- Очень сложные противники рассчитаны на подготовленного одиночного игрока. Групповые бои — будущий этап.
- Босс появляется как редкая случайная встреча во время прогулки.
- При выпадении встречи с боссом бой начинается сразу. Бесплатного отказа до боя нет.
- Уход от босса — через существующее действие «Сбежать»: шанс успеха 50%, при неудаче противник наносит удар и бой продолжается.
- Старый набор мобов полностью заменяется; квесты перерабатываются под новый набор. Старые цели не должны требовать отсутствующих противников.
- Перед внедрением выбираем названия в стилистике бытового абсурда существующих предметов. Предложения с привязкой к площади Ленина в Новокуйбышевске вынесены в [отдельный документ](SQUARE_MOBS_PROPOSAL.md).

## Предлагаемая модель баланса

Разделить уровень и класс сложности. Уровень задаёт базовые HP, силу и защиту, класс — дополнительную сложность и доступные приёмы. Рассчитать отдельные таблицы по уровням, учитывая существующие очки характеристик и экипировку персонажа. Снаряжение игрока не должно автоматически усиливать противника: улучшение экипировки сохраняет пользу.

Предложены четыре класса, численные границы ещё не утверждены:

| Класс | Роль |
| --- | --- |
| Обычный | Основные бои, обучение применению приёмов и начальная добыча |
| Сильный | Требует более внимательного выбора действий |
| Элита | Проверяет экипировку, защиту и применение лечения |
| Босс | Очень трудный, но проходимый соло бой для подготовленного персонажа |

Уровень и параметры конкретной встречи рассчитывать на сервере и сохранять для начатого боя. Один вид противника может иметь разный уровень у разных игроков; общую запись шаблона нельзя перезаписывать под каждого из них. Встреча и бой не должны заново разыгрываться при обновлении страницы или переподключении.

Для мобов предлагаются обычные и сильные атаки, для сложных — дополнительные приёмы из возможностей движка. ИИ не читает скрытый выбор игрока; предварительное объявление сильной атаки не вводится. Балансировать с действующими правилами: без скорости, защита раньше атак, случайная очередь равного приоритета, одно лечение на участника за новый бой.

## Добыча и экономика — для согласования

Предлагаемый доступ к редкостям, а не гарантированное выпадение:

| Уровень встречи | Максимальная открываемая редкость |
| --- | --- |
| 1 | Обычная |
| 2 | Необычная |
| 3–4 | Редкая |
| 5–6 | Эпическая у элиты и боссов |
| 7–8 | Легендарная у самых сложных боссов |

Предыдущие редкости, расходники и материалы остаются в наборах добычи. Новые предметы из существующего каталога распределяются между противниками. Предлагается общий розыгрыш экипировки по редкости и предмету внутри пула; материалы и расходники — дополнительные проверки. Точные вероятности и изменение существующего независимого розыгрыша ещё не утверждены.

Монеты, опыт и шансы предметов считать вместе со временем боя, вероятностью поражения, затратами на лечение, частотой встреч и независимой ценой выкупа NPC. Действующая ценовая шкала предметов — вариант A из [обновления предметов](ITEM_UPDATE.md). Не рассчитывать прибыль только по магазинной цене покупки или возможному джекпоту казино.

## Перед заменой старого набора

- Выбрать точные кривые HP/силы/защиты, приёмы и поведение каждого класса.
- Определить вероятности встреч во время прогулки (включая шанс босса), личные ограничения частоты и правила после побега/поражения. Действие уже согласовано: прогулка.
- Рассчитать награды и полные пулы предметов, проверить серии боёв с разными сборками. Не назначать победу отдельным случайным броском: исход определяется ходами и обычными правилами боя.
- Отдельно определить роль учебного противника; предложено сохранить простой первый бой.
- Подготовить замену связанных квестов и сохранение истории: у `combat_sessions.mob_id` сейчас каскадное удаление при удалении моба. Активные сессии и историю нельзя потерять при замене каталога.
- Удалить старые сидовые определения из запуска при фактической замене, чтобы старые мобы не вернулись после перезапуска.
- Согласовать предложенные названия и описания; первый выпуск разместить только на «Площади». Затем внедрить замену каталога и квестов вместе с проверенным численным балансом.
