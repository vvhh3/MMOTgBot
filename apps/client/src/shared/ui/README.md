# Общие стили интерфейса

`components.css` подключён из `app/styles.css` и используется как основным приложением, так и витриной `/ui`.

| Класс | Назначение |
| --- | --- |
| `game-button` | Основное действие, цвет `#e8603c` |
| `game-button--danger` | Отмена, отклонение, удаление |
| `game-button--outline` | Дополнительное действие с контуром |
| `game-button--glass` | Основное действие казино |
| `game-button--online`, `game-button--offline` | Состояние сети |
| `game-button--xs`, `--sm`, `--lg` | Размер кнопки |
| `game-button--icon`, `--step` | Круглая кнопка добавления или изменения числа |
| `modal-close-button` | Прозрачное закрытие с чёрным × |
| `game-card` | Карточка по образцу обучения |
| `game-card--white`, `--glass` | Белая или стеклянная поверхность |
| `modal-surface`, `modal-title` | Единое оформление окна и заголовка |
| `game-badge` | Мягкая метка; `data-tone="ready/busy/offline"` задаёт состояние |
| `game-input` | Поле ставки с прозрачным фоном |
| `game-table` | Стеклянная таблица из `table.css` |

Модификаторы используются вместе с базовым классом, например `game-button game-button--danger`.

Раскладка, ширина и внешние отступы задаются Tailwind: `className="game-button mt-4 w-full"`. Одноразовые отличия задаются utility-классами; `!` нужен только при переопределении свойств Radix или общего оформления. В `style` остаются значения, зависящие от данных: ширина здоровья, координаты карты, изображения.

Для уровня используется `LevelBadge`: белый фон без контура, оранжевая звезда и «Ур.» с числом. Этот вид общий для шапки, карточек, таблиц и окон. Для иконок действий используется `ActionIcon`. Состояния клеток казино общие для мин и лестницы: `casino-cell` с `data-state="closed/safe/bomb"`. Оформление боя, казино, группы и сложности задания хранится рядом с соответствующей feature и также подключается из `app/styles.css`.
