# @mmobot/server

Серверная часть MMOBot: HTTP API (Express), реальное время (Socket.IO), Telegram-бот (grammy) и работа с базой данных (SQLite + Drizzle).

## Структура и назначение папок

| Путь | Назначение |
| --- | --- |
| `src/` | Исходный код сервера (TypeScript). |
| `src/db/` | Определение схемы базы данных (Drizzle ORM). |
| `drizzle/` | Сгенерированные миграции БД (`drizzle-kit generate`). Не редактировать вручную. |
| `data/` | Файлы SQLite-базы (`mmobot.db`) и картинки локаций. Создаются автоматически. |
| `dist/` | Результат сборки (`tsc`). Генерируется, не редактировать. |
| `apps/server/data/` | Вложенная копия данных, появившаяся при запуске из другого каталога. Не нужна. |

## Назначение файлов

| Файл | Что делает |
| --- | --- |
| `package.json` | Метаданные пакета и npm-скрипты (`dev`, `build`, `db:migrate`, `typecheck` и т.д.). |
| `tsconfig.json` | Настройки компилятора TypeScript. |
| `drizzle.config.ts` | Конфигурация drizzle-kit (путь к схеме и к миграциям). |
| `src/index.ts` | Точка входа: стартует Express + Socket.IO сервер и фоновое обслуживание (`maintenance`). |
| `src/app.ts` | Создание Express-приложения: CORS, JSON, все маршруты API, раздача статики клиента. |
| `src/auth.ts` | Аутентификация: проверка Telegram `initData`, выпуск/проверка сессионных токенов, middleware `requireAuth` / `requireAdmin`. |
| `src/config.ts` | Загрузка конфигурации из `.env` (токен бота, порт, пути, CORS). |
| `src/db.ts` | Подключение к SQLite через Drizzle, миграции, сид локаций, мапперы «строка БД → DTO». |
| `src/db/schema.ts` | Drizzle-схема таблиц: `locations`, `players`, `inventory_items`, `events`, `mobs`, `items`, `quests`, `trades`, `pvp`, `friendships` и др. |
| `src/time.ts` | Игровое время UTC+4: форматирование, разницы меток времени, граница игрового дня. |
| `src/level.ts` | Уровни и опыт: пороговая таблица, выдача очков характеристик за уровень. |
| `src/regen.ts` | Регенерация здоровья игрока с течением времени. |
| `src/presence.ts` | In-memory отслеживание игроков по локациям (кто где находится). |
| `src/state.ts` | Сборка состояния локации: игроки, действия, живые мобы, события. |
| `src/combat.ts` | Бой с мобом: начало, ходы (атака/побег/зелье), лог боя, лут, начисление опыта, респаун. |
| `src/pvp.ts` | Дуэли между игроками: вызов, приём, поочерёдные ходы, учёт экипировки. |
| `src/trades.ts` | Обмен предметами между игроками (флоу как в Steam: приглашение → окно → «готово»). |
| `src/quests.ts` | Квесты: ежедневные (по сложности), прогресс, награды и выдача опыта. |
| `src/inventory.ts` | Инвентарь: список предметов, экипировка/снятие. |
| `src/mobs.ts` | CRUD мобов (админ-доступ). |
| `src/items.ts` | CRUD предметов (админ-доступ). |
| `src/addFriends.ts` | Друзья: заявки на дружбу, принятие/отклонение, поиск по friendId. |
| `src/realTime.ts` | Socket.IO: push-состояние локаций, событий боя, инвентаря и PvP в реальном времени. |
| `src/notification.ts` | Отправка уведомлений игрокам в Telegram (очередь с задержкой). |
| `src/maintenance.ts` | Фоновое обслуживание: очистка старых событий, зависших трейдов и боёв. |
| `src/bot.ts` | Точка входа Telegram-бота: команда `/start` и кнопка открытия Mini App. |

## Что реализовано

- Авторизация через Telegram `initData` с проверкой подписи; выдача JWT-токена
- Профиль игрока, уровни/опыт и трата очков характеристик (`POST /me/stats`)
- Регенерация здоровья, игровое время UTC+4
- Локации: список, состояние (игроки, действия, живые мобы, события), вход, действия «сражаться»/«прогуляться» с лотом и опытом
- Бой с мобом: начало, ходы (атака/побег/зелье), лог боя, лут, начисление очков, респаун
- Дуэли (PvP) между игроками с учётом экипировки
- Обмен предметами между игроками
- Ежедневные квесты с прогрессом и наградами
- Инвентарь и экипировка предметов
- Друзья: заявки, поиск по friendId, уведомления
- Лидерборд и состояние онлайн-игроков
- Реальное время через Socket.IO (push вместо поллинга)
- CRUD мобов и предметов (админ-доступ)
- SQLite (better-sqlite3 + Drizzle ORM), миграции, сид стартовых локаций и мобов
- Telegram-бот на grammy (кнопка «Открыть город», уведомления)
- Фоновое обслуживание: очистка зависших сессий боёв/дуэлей/трейдов и старых событий

## Что не реализовано

Реальный контент локаций, финальный дизайн, чат, кланы и гильдии, торговля за игровую валюту (есть только обмен предметами).

## Команды

- `npm run dev` — запуск API-сервера в режиме разработки
- `npm run dev:bot` — запуск Telegram-бота в режиме разработки
- `npm run build` / `npm start` — сборка и запуск из `dist/`
- `npm run typecheck` — проверка типов
- `npm run db:generate --workspace @mmobot/server` — создать миграцию
- `npm run db:migrate --workspace @mmobot/server` — применить миграции
- `npm run db:studio --workspace @mmobot/server` — открыть Drizzle Studio
