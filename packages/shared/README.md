# @mmobot/shared

Общие контракты и игровые определения клиента и сервера.

- `src/index.ts` — публичные экспорты пакета.
- `src/contracts/` — DTO запросов, ответов и socket-событий по игровым областям.
- `src/combat.ts` — модель боя, действий и событий.
- `src/weapons.ts` — оружие, редкости и определения пассивок.

Импортировать через `@mmobot/shared`. Здесь не должно быть зависимостей от приложений, UI, сетевых запросов или базы данных.

Сборка: `npm run build --workspace @mmobot/shared`. Полная [карта проекта](../../docs/architecture.md).
