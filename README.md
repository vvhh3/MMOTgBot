# MMOBot — MVP Telegram Mini App

Минимальный рабочий скелет Telegram Mini App: авторизация через `initData`, REST API, SQLite в режиме WAL, список локаций, вход в локацию, HTTP-поллинг состояния локации и одно тестовое действие.

## Что реализовано

**Бэкенд (Express REST API)**
- Авторизация через Telegram `initData` с проверкой подписи; выдача JWT-токена
- Профиль игрока (`GET /me`) и его инвентарь
- Локации: список, состояние (игроки, действия, живые мобы, события), вход в локацию, действие «поиск припасов»
- Бой с мобом: начало, ходы (атака/побег), лог боя, лут, начисление очков, респаун мобов
- CRUD мобов и предметов (админ-доступ)
- SQLite (better-sqlite3 + Drizzle ORM), миграции, сид стартовых локаций и мобов
- Telegram-бот на grammy с кнопкой «Открыть город» для запуска Mini App

**Фронтенд (React + Vite)**
- Скелет клиента: подключение к Telegram WebApp, API-клиент, компоненты загрузки

**Общий пакет (`@mmobot/shared`)**
- Все DTO запросов и ответов API, переиспользуемые клиентом и сервером

## Что не реализовано

Реальный контент локаций, финальный дизайн, чат, PvP, торговля и гильдии.
